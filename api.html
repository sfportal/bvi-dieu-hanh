API cho đối tác

Lấy dữ liệu vùng trồng, công việc, lịch công tác và các dữ liệu liên quan từ hệ thống BVI Điều hành. API chỉ đọc, phiên bản v1.

Bắt đầu

  1. Nhận khóa API từ BVI (dạng bvi_ + 40 ký tự). Mỗi khóa chỉ đọc được các loại dữ liệu BVI đã cấp và có thể có thời hạn.
  2. Gọi địa chỉ gốc dưới đây kèm khóa trong header.
  3. Gọi GET /v1 trước để xem khóa của bạn được đọc những gì.
Địa chỉ gốc
https://pkckduidwfcncipwzdxa.supabase.co/functions/v1/api/v1
Giữ khóa như mật khẩu: chỉ dùng ở máy chủ của bạn, không đặt trong ứng dụng web hay app điện thoại công khai. Lộ khóa thì báo BVI để thu hồi và cấp khóa mới.

Xác thực

Gửi khóa trong header X-API-Key. Cũng chấp nhận Authorization: Bearer <khóa>. Chỉ dùng phương thức GET.

X-API-Key: bvi_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Giới hạn: 120 lượt mỗi phút cho mỗi khóa. Vượt giới hạn trả mã 429, chờ 60 giây rồi gọi lại.

Vì lý do bảo mật, API không bao giờ trả số CCCD, sổ đỏ, số điện thoại, email, số tiền hợp đồng, link Google Drive và ảnh hiện trường.

Tham số, phân trang

Tham sốÝ nghĩa
limitSố bản ghi mỗi trang, 1 đến 1000, mặc định 500
offsetBỏ qua N bản ghi đầu. Lấy trang tiếp bằng giá trị next_offset của trang trước
updated_sinceThời điểm ISO 8601, ví dụ 2026-11-01T00:00:00Z. Chỉ trả bản ghi sửa từ lúc đó, dùng để đồng bộ định kỳ

Cách đồng bộ khuyến nghị: lần đầu lấy toàn bộ, lưu lại thời điểm bắt đầu gọi. Các lần sau gọi với updated_since bằng thời điểm đã lưu. Gọi 15 đến 60 phút một lần là đủ.

Kết quả

Dữ liệu trả dạng JSON, mã hóa UTF-8. Danh sách có dạng:

{
  "resource": "zones",
  "total": 105,
  "offset": 0,
  "limit": 500,
  "next_offset": null,
  "data": [
    {
      "id": "z014-hoi-buon-ho",
      "updated_at": "2026-11-05T11:56:57Z",
      "name": "VÙNG TRỒNG SẦU RIÊNG HỘI BUÔN HỒ",
      "ward": "Xã Krông Búk",
      "province": "Đắk Lắk",
      "ha": 14.63,
      "hh": 9,
      "step": 5,
      "priority": "1",
      "eta": "15–20/11/2026",
      "customer": "Yanning Hải Nam",
      "next": "Nhận yêu cầu bổ sung của xã",
      "blocker": "Chưa nhận yêu cầu bổ sung cụ thể của xã…",
      "inspected": true
    }
  ]
}

Một bản ghi (/v1/zones/<id>) trả {"data": {...}}. Bản ghi có thể thiếu trường khi chưa có dữ liệu, hãy xử lý trường vắng mặt như rỗng.

Ví dụ

curl

curl -H "X-API-Key: $BVI_API_KEY" \
  "https://pkckduidwfcncipwzdxa.supabase.co/functions/v1/api/v1/zones?limit=100"

JavaScript (Node 18+)

const BASE = "https://pkckduidwfcncipwzdxa.supabase.co/functions/v1/api/v1";
async function getAll(resource, since) {
  const out = [];
  let offset = 0;
  while (offset !== null) {
    const q = new URLSearchParams({ limit: "1000", offset: String(offset) });
    if (since) q.set("updated_since", since);
    const r = await fetch(`${BASE}/${resource}?${q}`, { headers: { "X-API-Key": process.env.BVI_API_KEY } });
    if (!r.ok) throw new Error(`${r.status} ${await r.text()}`);
    const page = await r.json();
    out.push(...page.data);
    offset = page.next_offset;
  }
  return out;
}
const zones = await getAll("zones");

Python

import os, requests
BASE = "https://pkckduidwfcncipwzdxa.supabase.co/functions/v1/api/v1"
H = {"X-API-Key": os.environ["BVI_API_KEY"]}

def get_all(resource, since=None):
    out, offset = [], 0
    while offset is not None:
        p = {"limit": 1000, "offset": offset}
        if since: p["updated_since"] = since
        r = requests.get(f"{BASE}/{resource}", headers=H, params=p, timeout=30)
        r.raise_for_status()
        page = r.json()
        out += page["data"]
        offset = page["next_offset"]
    return out

tasks = get_all("tasks", since="2026-11-01T00:00:00Z")
